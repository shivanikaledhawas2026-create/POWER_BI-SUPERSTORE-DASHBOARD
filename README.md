# POWER_BI-SUPERSTORE-DASHBOARD
Interactive Power BI dashboards built using the Superstore dataset.
## 📌 Project Overview
This project showcases interactive dashboards built in **Power BI** using the popular **Superstore dataset**.  
The goal is to transform raw sales data into actionable business insights for decision‑making.

## 🎯 Key Objectives
- Analyze sales performance across categories, regions, and time.
- Identify profitable vs. loss‑making orders.
- Understand customer behavior and segmentation.
- Evaluate shipping and delivery efficiency.
- Provide executive‑level KPIs for quick insights.

## 📊 Dashboards Included
1. **Sales Overview** – Revenue, profit, and order trends with category/region breakdowns.  
2. **Customer Insights** – Segmentation by region, lifetime value, and purchase behavior.  
3. **Product Performance** – Top‑selling and underperforming products with profit margins.  
4. **Regional Analysis** – Map and charts showing sales distribution across states/cities.  
5. **Shipping & Delivery** – Average delivery days, shipping costs, and carrier performance.  
6. **Profitability** – Profit vs. loss orders, discount impact, and contribution by category.  
7. **Executive Summary** – One‑page snapshot with KPIs for leadership decision‑making.  

## 🛠️ Tools & Skills Demonstrated
- **Power BI** – Data modeling, visualization, and storytelling.  
- **DAX** – Custom measures (e.g., Loss Order %, Avg Delivery Days).  
- **Excel & SQL** – Data preparation and exploration.  
- **Data Visualization Best Practices** – Clean layouts, conditional formatting, KPI cards.
